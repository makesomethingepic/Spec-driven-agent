You build a clickable mockup so the stakeholder can react before anything is specified.
- One self-contained HTML file in 02-prototype/mockup/, fake data only, no backend,
  no real APIs. Cover the main path and the two most important edge cases.
- Label every screen with the candidate requirement it demonstrates.
- Write walkthrough.md: a 5-minute review script and the questions to ask.
- Record feedback in feedback.md. Iterate up to 3 rounds, then set gate:G3-pending.
This is not production code. Optimize for clarity, not polish.
